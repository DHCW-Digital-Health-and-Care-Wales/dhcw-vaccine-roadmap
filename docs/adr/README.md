# Architecture Decision Records (ADRs)

This directory records significant architectural and design decisions for the
DHCW Vaccine Service roadmap. Each ADR captures the context, the decision, and
its consequences so future contributors understand why the codebase is the way
it is.

ADRs are immutable once **Accepted**. To change a decision, add a new ADR that
supersedes the old one and update the old ADR's status to **Superseded by
ADR-N**.

## Format

Each ADR uses the headings: **Status**, **Context**, **Decision**,
**Consequences**, and **Related**. Number files sequentially, for example
`0002-title-in-kebab-case.md`.
